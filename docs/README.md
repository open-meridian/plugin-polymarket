# The Polymarket plugin's documentation

A draft, for a deployment admin who adds Polymarket's market data for its
outcome tokens to a deployment. It is written ahead of the
plugin-documentation revision, which will say where a plugin's documentation
is published; until then it lives here, beside the code.

- [Overview](overview.md): what the plugin does, and what it never does.
- [Setup](setup.md): launching it, licensing and entitling its dataset.
- [Pages](pages.md): Connection and Datasets, and their tools for agents.
- [Troubleshooting](troubleshooting.md): what each thing you might see means.
